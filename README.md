# ✦ 花火贺卡 Hanabi

为想念的人，做一张清爽的小贺卡。

选一个灵感样式，填上名字与祝福，寄出一条链接——对方打开，就是一场
信封开启、标题逐字亮起、祝福缓缓浮现的小演出。纸白底色、素净排版，
极简、高级、清新。

**纯前端 · 无后端 · 零依赖**：整张贺卡的配置被编码进链接本身（base64url + `#hash`），
不存储任何数据，链接即贺卡。

---

## 功能

- **七种 Canvas 粒子效果**：烟花、彩带、星空、飘雪、樱花、流星雨、天灯，
  辉光用预渲染粒子精灵绘制（纸白底上是水彩晕染质感），自带重力、拖尾，
  适配高分屏（devicePixelRatio）。
- **六套主题**：纸白四套——素笺（默认）、雾青、樱贝、暮沙；
  夜帖两套——夜空、墨夜（深底月白字，粒子恢复夜空辉光）。
- **照片入卡**：上传一张照片，本地压缩后随链接寄出，
  在贺卡里以拍立得呈现，轻触可放大；装不下链接时「贺卡文件」完整携带。
- **语音祝福**：编辑器里现场录一段（≤60 秒），收卡人点开信封先闻其声，
  语音结束音乐才起；微信/iOS 手势解锁照常。
- **手写署名**：手写板上写名字，播放时笔迹一笔一划重现，再盖青瓷印。
- **多页祝福**：祝福语里单独一行「---」即分页，收卡人读完轻触翻页。
- **帖号签语**：每张卡的帖号确定性对应一句签语（同一链接永远同签），
  播放结尾浮现「第 xxxx 签 · …」。
- **深度自定义**：粒子密度 0.2×~2× 滑杆；强调色、背景色任选
  （选"自动"跟随主题，背景色自动派生深浅层次）；草稿自动保存。
- **十一种场景**：生日 / 新春 / 中秋 / 毕业 / 表白 / 感谢 / 圣诞 / 教师节 /
  七夕 / 乔迁 / 通用，切换场景自动带入应景文案；生日独有**礼物盒开场 +
  吹蜡烛**（火灭冒烟、画面变亮），圣诞也走礼盒开场。
- **三种卡面字体**：手写楷 / 典雅宋 / 现代黑。
- **彩蛋效果**（收卡人打开时触发，全部有界、可关闭，绝无无限弹窗）：
  屏幕震动 / 弹窗雨（自绘可关闭的祝福小窗）/ 跑路红包（追不上的按钮，
  抓住后爆爱心）/ 祝福弹幕（祝福语飘过屏幕）。
- **灵感样式**：七套成品组合一键套用，再微调；「来点手气」随机换一套。
  灵感卡里就是真实粒子效果的预览，悬停即动；没词时「帮你起两句」
  从本地灵感库组合祝福，离线可用。
- **卡片细节**：竖排称呼、题下细线描画、署名旁一点青瓷、
  由链接推导的专属编号与签语、微信标题栏跟随内容。
- **自定义信笺（主要功能）**：上传你自己的 HTML 网页当贺卡——里面写
  `{{收件人}}` `{{标题}}` `{{祝福语}}` `{{署名}}` 占位符，寄出时自动替换成
  填写的内容；收卡人在沙盒 iframe 里看到的就是你亲手写的页面，粒子与爱心照常。
- **六种寄出方式**：贺卡链接 / 贺卡文件 / 网页祝福邮件 / 邮件应用 /
  短信 / 实体贺卡（排好版的对折卡面，打印寄出）；
  另有「下载发送提醒 (.ics)」帮你记住寄出的日子。
- **回赠动线**：贺卡结尾是「回 TA 一张」——收发对调、样式一并带去编辑器，
  来往就成了一条线。
- **网页祝福邮件**：自动排版的邮件正文（纸白信笺、墨色按钮、
  「打开会动的贺卡」按钮），渲染预览 + 一键富文本复制，粘贴进
  Gmail / QQ 邮箱正文即成；也可填写邮箱直接唤起邮件应用。
- **实时预览**：右侧手机壳 iframe，改动即时同步（postMessage 热更新）。
- **自定义音乐**：页面本身不带任何音乐，静默开场；可上传自己的
  mp3 / m4a / wav 等音频作贺卡曲——≤300KB 直接随链接送达，
  更大用「导出贺卡文件」（自带音频的独立 .html，离线双击即播）。
- **尊重系统动效偏好**：`prefers-reduced-motion` 下粒子凝为静态画面、动画精简。
- **微信内置浏览器可用**：无外部资源、复制有降级方案、音频在用户手势后启动。

## 快速开始

1. 下载/克隆本仓库；
2. **双击 `index.html`** 即可开始制作（本地预览）；
3. 或部署到 Vercel 在线使用（推荐，见下文）。

> 本地双击运行生成的 `file://` 链接只能自己打开；分享给别人请先部署。

## 使用

1. 在「灵感」页挑一套起点；
2. 在「内容」页写给谁、写什么（可上传照片、录一段语音、手写签名，
   用「---」把祝福分成几页）；在「样式」页调主题/粒子/字体/颜色/彩蛋，
   可上传音乐；想用自己的设计就去「信笺」页上传 HTML（写上 `{{收件人}}` 等占位符）；
3. 在「寄出」页挑一种方式：**贺卡链接 / 贺卡文件 / 祝福邮件 / 邮件应用 /
   短信 / 实体贺卡**；
4. 发给 TA（微信 / QQ / 邮箱 / 短信均可），打开即播；结尾 TA 可以「回 TA 一张」。

> 编辑器顶部导航栏按步骤分页，右侧手机预览在任何页都常驻实时同步；
> 所有改动自动保存草稿，关页面再开不丢。

播放中的小机关：

| 机关 | 说明 |
| --- | --- |
| 点按开启 | 信封（通用）或礼盒（生日·圣诞）开场，同时开始播放语音与音乐 |
| 翻页 | 祝福分了几页时，读完一页轻触屏幕翻页 |
| 跳过 › | 右上角随时直达结尾（键盘 Esc 同效） |
| 吹蜡烛 | 生日专属：点按钮或直接点蛋糕 |
| 轻触夜空 | 任意时刻赠出一颗心（末页状态） |
| ♪ 音乐 | 左上角播放 / 暂停（仅当对方贺卡带了音乐时出现） |
| 轻触照片 | 放大 / 还原那张拍立得 |
| 第 xxxx 签 | 结尾浮现的帖号签语，同一链接永远同一句 |

**关于自定义音乐的两种送法**

- 链接送：音频 ≤ 300KB（约半分钟 64kbps）会直接编码进链接，对方点开就有；
- 文件送：更大的音乐用「导出贺卡文件」，生成自带全部样式与音频的独立
  `.html`，微信/QQ 当文件发过去，对方下载后双击即可离线播放，不依赖网络。
- 页面原生不带任何音乐；不上传就是静默开场。

**关于自定义信笺（上传 HTML）**

- 在「肆 · 信笺」上传你的 `.html`（≤4MB），可写 `{{收件人}}` `{{标题}}`
  `{{祝福语}}` `{{署名}}` 占位符，寄出时自动替换；不写则原样寄出。
- 四种寄出通道对信笺的支持：

| 通道 | 信笺支持 | 说明 |
| --- | --- | --- |
| 贺卡链接 | ≤ 260KB | 整份信笺编码进链接，点开即播 |
| 贺卡文件 | ≤ 4MB | 内嵌进独立 .html，离线可播 |
| 祝福邮件 | ≤ 4MB | 信笺即邮件正文（占位符已替换） |
| 邮件应用 | 任意 | 邮件正文为纯文本祝福 + 贺卡链接 |

- 超过 260KB 时「贺卡链接」会拒绝生成并提示改道，避免寄出缺了正文的贺卡。
- 信笺在收卡端运行于沙盒 iframe（可运行脚本、不可访问父页面），放心写动画。

## 部署到 Vercel（零配置）

**方式一：GitHub 导入（推荐）**——仓库推到 GitHub 后，在
[vercel.com/new](https://vercel.com/new) 导入，全部默认，Deploy 即可。

**方式二：Vercel CLI**

```bash
npm i -g vercel     # 只全局装 CLI，项目本身零 npm 依赖
cd Hanabi
vercel --prod
```

**方式三：网页拖拽**——把项目文件夹拖进 [vercel.com/new](https://vercel.com/new)。

部署后得到 `https://你的项目名.vercel.app`，编辑器生成的链接自动指向该域名。

## 核心机制

配置共 17 个字段：
`{ to, title, message, from, occasion, theme, effect, font, music, voice, photo, sign, custom, density, accent, bg, prank }`。
其中 `music` / `voice` 为 `off`（无，默认）或 `data:audio` 音频，`photo` 为
压缩后的 `data:image`，`sign` 为量化的手写笔迹——四者都由编辑器在本地生成；
任何一项超过链接承载上限时生成链接会自动去掉该项，改由导出文件完整携带。

编辑器把配置 `JSON → UTF-8 → base64url` 后拼到 `card.html#<code>`；播放器解析
`location.hash` 还原配置，解析失败或没有 hash 时回落到默认演示。
全程无网络请求、无 Cookie、无后端——**隐私天然安全**。
帖号（NO.xxxx）与签语都由链接字符串确定性推导，同一链接永远同号同签。

## 如何贡献一个新粒子效果

引擎约定：效果通过 `registerEffect(name, { init, tick, stop })` 注册，
引擎负责画布、DPR、resize、每帧清屏与 RAF 循环，你只管画。

**第一步：在 `js/effects.js` 末尾注册**

```js
/* 示例——萤火虫 */
registerEffect('fireflies', {
  label: '萤火虫',          // 编辑器里显示的中文名
  desc: '仲夏夜之光',        // 一句话描述（悬停提示）
  init: function (ctx, w, h, opts) {
    // opts.palette 是当前主题的粒子配色（数组）
    var colors = opts.palette;
    var bugs = [];
    for (var i = 0; i < 40; i++) {
      bugs.push({ x: Math.random() * w, y: Math.random() * h, ph: Math.random() * 6.28 });
    }
    // init 返回 { tick }；窗口尺寸变化时 init 会被再次调用
    return {
      tick: function (c, dt, time) {
        // dt：距上一帧的秒数；time：自启动起的秒数
        c.globalCompositeOperation = 'lighter';
        for (var i = 0; i < bugs.length; i++) {
          var b = bugs[i];
          b.x += Math.sin(time * 0.7 + b.ph) * 22 * dt;
          b.y += Math.cos(time * 0.5 + b.ph) * 16 * dt;
          var glow = 0.5 + 0.5 * Math.sin(time * 2 + b.ph * 3);
          c.globalAlpha = glow;
          c.fillStyle = colors[i % colors.length];
          c.shadowColor = c.fillStyle; c.shadowBlur = 12;
          c.beginPath(); c.arc(b.x, b.y, 2, 0, 6.283); c.fill();
        }
        c.globalAlpha = 1; c.shadowBlur = 0;
        c.globalCompositeOperation = 'source-over';
      }
      // 如有定时器等资源，可再返回 stop: function () {...} 供引擎清理
    };
  }
});
```

**第二步：加进 `js/config.js` 的兜底白名单**（加载顺序原因，校验用）：

```js
var FALLBACK_EFFECTS = ['fireworks', 'confetti', 'starfield', 'snow', 'petals', 'meteor', 'fireflies'];
```

完成。编辑器会自动出现你的效果，预览与成卡即时可用。

**约定与建议**

- 画布已按 devicePixelRatio 缩放，坐标一律按 CSS 像素写；
- 动画只用 Canvas / `transform` / `opacity`，不要触发布局属性；
- 粒子数量按屏幕面积伸缩（参考现有效果的 `w * h / N` 写法），手机端上限约 200；
- `opts.reduced === true` 时引擎只渲染一帧静态画面，无需特殊处理；
- 提 PR 前请用手机宽度（≤ 430px）自测一遍流畅度。

**新增主题**：在 `js/themes.js` 的 `DEFS` 里加一组 CSS 变量与 `palette` 即可。
**新增灵感样式**：在 `js/config.js` 的 `TEMPLATES` 里加一项即可。
